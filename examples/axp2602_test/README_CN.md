# AXP2602 充放电测试示例

## 功能

本示例使用 `lewisxhe/SensorLib@^0.4.1` 的 `GaugeAXP2602` 驱动，在
T5 E-Paper Basic 屏幕上显示：

- 电池端电压 VBAT。
- 双向电池电流、充电电流和放电电流。
- 瞬时电池功率。
- SOC、SOH。
- 预计放空时间 TTE 和预计充满时间 TTF。
- 温度结果和 AXP2602 芯片温度。
- 工作模式、采样电阻、测量使能状态。
- IRQ 原始状态、IRQ 类型和计数。
- GPIO5 USB 输入检测和 GPIO4 充电状态。

引脚：

| 功能 | 引脚 |
| --- | --- |
| I2C SCL | GPIO2 |
| I2C SDA | GPIO3 |
| AXP2602 IRQ | GPIO21 |
| 充电状态 `CHG_STAT` | GPIO4 |
| USB 输入检测 `USB_DET` | GPIO5 |
| 电量计休眠/唤醒测试 | BOOT / GPIO0 |

## 重要说明

AXP2602 是单节锂电池电量计，不是充电管理芯片。板上实际充电芯片是
LGS4056HDA。

AXP2602 没有 VBUS ADC，因此不能读取独立的“充电输入电压”。屏幕上的充电输入
电压会显示“不支持”，GPIO5 只能检测 USB 输入是否存在，不能测量其准确电压。

AXP2602 也没有控制整机电源通断的输出。`sleep()` / `wakeup()` 只控制电量计自身，
休眠时电量计功耗低于 0.5 µA，但 ESP32 和整板电源不会关闭。

## 电流方向

本示例遵循 SensorLib 0.4.1 的实际实现：

- 电流大于 0：充电。
- 电流小于 0：放电。
- 接近 0：空闲。

电流单位是 mA，不是 mAh。建议首次测试时通过插拔 USB 和连接已知负载确认板级
采样电阻方向。

## 控制

- 短按 BOOT：切换 AXP2602 电量计休眠/唤醒，不关闭整机。
- 串口 `S`：电量计休眠。
- 串口 `W`：唤醒电量计。
- 串口 `R`：复位并重新配置电量计。
- 串口 `H`：显示帮助。

## SOC 精度

准确的 SOC、SOH、TTE 和 TTF 依赖与实际电池匹配的 128 字节模型参数。本示例不会
在每次启动时写入电池模型，以免覆盖已有参数或反复写入错误模型。未加载匹配模型时，
这些数值只适合做通信和变化趋势测试，不应作为绝对精度判定依据。

## 编译

根目录 `platformio.ini` 当前配置为：

```ini
src_dir = examples/axp2602_test
```

执行：

```powershell
pio run -e T5_E_PAPER_BASIC
```
